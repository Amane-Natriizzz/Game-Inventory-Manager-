# Game Inventory Manager

A simple Java console-based inventory management system.

## Features

- Add items
- Add items with quantity
- Show all items
- Remove duplicate items
- Sort items alphabetically
- Sort items with quantity
- Search items by name
- Search items by quantity
- Display items using Queue
- Exit program

## Java Collections Used

- `ArrayList`
- `HashMap`
- `HashSet`
- `TreeMap`
- `Queue`
- `LinkedList`

## Other Concepts

- Methods
- Loops
- Switch
- Exception Handling
- Scanner
- Generics
